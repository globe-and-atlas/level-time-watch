# Six styles reused one numeral font

Version 0.1.0 changed palettes and supporting details but rendered Ink, Paper, Amber, Field, and Signal with the same LECO 60 Bold digits. Only Quiet changed font. The first gallery expansion made this visible, and the user called it out.

The cause was a validation gap: the first release contract checked that six named styles existed, but did not require different numeral silhouettes or compare native style captures side by side. The visual references were treated mainly as palette guidance.

Version 0.1.1 assigns separate numeral fonts to all six styles, includes the original font licenses for custom resources, and refreshes the PBW and native gallery. Future style releases should compare all styles at one clock time, with color ignored, before publication.
